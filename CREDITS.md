# Credits

## The engine

TamaDigi is built on **TamaPoke**, created by **Quique Tortosa** —
[socquique/TamaPoke](https://github.com/socquique/TamaPoke), MIT licensed, © 2026.
The firmware, the sprite format, the six-language UI, the ES8311 audio bring-up and
the browser installer are his work. The forks by
[DylanPDao](https://github.com/DylanPDao/TamaPoke) and
[eperdeme](https://github.com/eperdeme/TamaPoke) added the move-based battle
system, the ladders, party and box, the peer-to-peer link, the checkpointed save,
the Game Boy-style synth, the emulator and the test suites.

TamaDigi replaces every Pokémon-specific part of that engine — data, rules, art,
music and text — with Digimon content and V-Pet rules. Everything it inherited is
used under the MIT licence.

## Chinese

The simplified Chinese UI is drawn with glyphs from **Fusion Pixel 12px** by
**TakWolf** ([TakWolf/fusion-pixel-font](https://github.com/TakWolf/fusion-pixel-font)),
under the **SIL Open Font License 1.1** (`tools/fonts/fusion-pixel-OFL.txt`). Only
the characters the game uses are rendered into `cjk_font.h` as bitmaps. The
translation has not been proofread by a native speaker; corrections to
`tools/zh_names.py` and the ZH row of `i18n.cpp` are welcome.

## Made for this project

Nothing below is taken from any game; it is generated by scripts in `tools/`:

| Asset | Script |
|---|---|
| Battle and victory music | `tools/gen_music.py` (original compositions) |
| Boss badges | `tools/gen_ladders.py` (geometric shapes in element colours) |
| Tamer avatars | `tools/gen_avatars.py` (hand-drawn as text) |
| Battle backgrounds | `tools/draw_backs.py` (procedural pixel scenes) |
| UI icons, egg, poop, heart | `tools/sprites.py` |
| Cries | `cry.h` (synthesised from each Digimon's stats) |
