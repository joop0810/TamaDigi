# TamaDigi v1.0.1

- **The display no longer goes dark for a moment after a tap.** The automatic dimming could think the screen had been untouched for weeks right after you tapped it and drop it to almost black, which happened most often in fights. Tapping never dims the screen now; it still dims by itself after 90 seconds without a touch.

**What you need to do:** install the firmware. Your save stays: leave "Erase device" unticked. The sprite packs on the SD card are unchanged.
